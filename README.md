# 🖥️ macOS-Style Personal Portfolio ✨

Welcome to my personal portfolio! This project is a fun, interactive, and visually appealing representation of my work, designed to mimic a macOS desktop environment directly in the browser.

> ⚠️ **Note**: This portfolio is specifically designed for **tablets and desktop screens** to provide the best window-management experience.

---

## 🌟 Features

- **🪟 Interactive Windows**: Draggable and manageable windows mimicking an OS interface.
- **💻 Terminal**: A functional-looking terminal window.
- **🧭 Safari**: A browser-like window for web projects or links.
- **📄 Resume Viewer**: A dedicated window to view my latest resume.
- **📁 Finder**: Browse through projects and files just like in macOS.
- **📝 Text Editor**: A text application for reading notes or descriptions.
- **🖼️ Image Content**: A gallery window for viewing images.
- **📬 Contact**: A clean interface to get in touch with me.
- **🖱️ Hover Effects**: Smooth text and icon hover animations.

---

## 🛠️ Tech Stack

This project was built using a modern frontend stack to ensure high performance and smooth animations:

- **[React 19](https://react.dev/)** - The library for web and native user interfaces.
- **[Vite](https://vitejs.dev/)** - Next Generation Frontend Tooling for fast builds and hot-module replacement.
- **[Tailwind CSS (v4)](https://tailwindcss.com/)** - A utility-first CSS framework for rapid UI development.
- **[GSAP](https://gsap.com/) & [@gsap/react](https://gsap.com/react/)** - Professional-grade animation library used for drag-and-drop windows and smooth hover effects.
- **[Zustand](https://zustand-demo.pmnd.rs/)** - A small, fast and scalable bearbones state-management solution.
- **[Lucide React](https://lucide.dev/)** - Beautiful & consistent icons.

## 🚀 Getting Started

If you'd like to run this project locally, follow these steps:

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**

   ```bash
   git clone <your-repo-url>
   cd portfolio
   ```

2. **Install the dependencies:**

   ```bash
   npm install
   ```

3. **Start the development server:**

   ```bash
   npm run dev
   ```

4. **Open in Browser:**
   Open [http://localhost:5173](http://localhost:5173) in your browser to see the portfolio in action.

---

## 🏗️ Build for Production

To build the project for production, run:

```bash
npm run build
```

You can preview the production build using:

```bash
npm run preview
```
